## Scope 2 mock API

This project uses a local json-server for dynamic product data.

### Install dependencies

```bash
npm install
```

### Start mock API

```bash
npm run server
```

The mock API will be available at:

- http://localhost:3000/bestsellers
- http://localhost:3000/bouquets

### Open the project

Open `index.html` with Live Server.

For GitHub Pages review, please use the repository files together with `db.json`.
